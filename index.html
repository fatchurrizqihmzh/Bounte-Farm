Apa itu Sistem Bioflok?
Inti Teknologi
Bioflok pada dasarnya adalah sistem manajemen amonia. Kotoran ikan menghasilkan amonia yang beracun jika menumpuk. Dalam sistem bioflok, bakteri baik (mikroba) mengubah amonia menjadi senyawa aman — bahkan menjadi gumpalan flok yang bisa dimakan ikan sebagai pakan alami. Kuncinya: keseimbangan C/N ratio (karbon–nitrogen), aerasi cukup, dan pemeliharaan air yang baik.
Keunggulan
• Hemat air — tidak perlu sering ganti air
• Efisiensi pakan tinggi (hemat 30–40%)
• Cocok untuk lahan terbatas
• Ramah lingkungan, limbah diolah di kolam
Tantangan & Mitigasi
• Butuh aerasi 24 jam → genset + blower backup
• Perlu paham manajemen air → SOP & test kit
• Modal awal lebih → terukur & terencana

Cara Setup (3 Menit)

    

      

        
1
Buka Google Sheets
Buat spreadsheet baru di sheets.google.com

        
2
Buka Apps Script
Klik menu Extensions → Apps Script

        
3
Copy-paste script ini
function doPost(e){
  try{
    var ss=SpreadsheetApp.getActiveSpreadsheet();
    var d=JSON.parse(e.postData.contents);
    var p=d.profile||'Bounte Farm';
    var sh=ss.getSheetByName(p)||ss.insertSheet(p);
    sh.getRange(1,1).setValue(JSON.stringify(d));
    sh.getRange(1,2).setValue(new Date().toISOString());
    return ContentService.createTextOutput(
      JSON.stringify({ok:true}))
      .setMimeType(ContentService.MimeType.JSON);
  }catch(err){
    return ContentService.createTextOutput(
      JSON.stringify({ok:false,error:String(err)}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
function doGet(e){
  var ss=SpreadsheetApp.getActiveSpreadsheet();
  var p=(e.parameter.profile)||'Bounte Farm';
  var sh=ss.getSheetByName(p);
  var out=sh?sh.getRange(1,1).getValue():'{}';
  return ContentService.createTextOutput(out||'{}')
    .setMimeType(ContentService.MimeType.JSON);
}

        
4
Deploy → Web App (CUKUP SEKALI)
Deploy → New deployment → Web App
Execute as: Me · Who has access: Anyone
Copy URL → paste di kolom atas → Sambungkan.
URL ini tetap (tidak berubah). Kalau nanti edit script, pakai Manage deployments → Edit → Version: New version supaya URL tetap sama — TIDAK perlu deploy ulang dari nol.

        
★
Biar pengguna lain TIDAK perlu setup
Programmer cukup tempel URL Web App ke variabel DEFAULT_GS_URL di dalam kode (bagian atas <script>), lalu deploy ulang situs. Semua device yang buka aplikasi otomatis tersambung ke Sheets yang sama — pengguna awam tinggal pakai, tanpa isi URL.

        
✓
Selesai!
Data auto-sync 2 arah. Buka dari HP, laptop, atau device manapun — data selalu sama (yang terbaru menang).
